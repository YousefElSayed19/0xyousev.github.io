# Personal site

Hugo + GitHub Pages. Push to `main` and the site rebuilds by itself.

## Add a write-up
1. Copy `archetypes`-style front matter from `content/writeups/example-format.md`.
2. Save it as `content/writeups/<short-name>.md`. The file name becomes the URL: `/writeups/<short-name>/`.
3. Commit. The site updates in about a minute.

Images: put them in `static/images/` and use `![alt](/images/name.png)`.
Posts dated in the future stay hidden until that date.

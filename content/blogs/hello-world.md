I'm Yousef, a penetration tester from Cairo. I've kept notes on everything I break for a while, in scattered files and half-finished repos. This site is where they go from now on, in a form I can share.

## What you'll find here

- **Write-ups** of CTFs and labs I've solved, in the [Writeups](/writeups/) section. Recon, the dead ends, and what finally worked.
- **Blog posts** like this one, for longer notes about tools, techniques and things I'm learning.
- **Projects**, mostly security labs and challenges I design, on the [projects page](/projects/).

## What I'm working on

Advanced web and API testing, Android security with Frida, reverse engineering, Active Directory, cloud security and AI/LLM security. I also design challenges, so expect posts about how a vulnerable app gets built, not just how it gets broken.

I'm Yousef El Sayed Mohamed, a penetration tester from Cairo, Egypt. My work is offensive security and hands-on vulnerability assessment: reconnaissance, enumeration, exploitation, privilege escalation and post-exploitation, across web, API, network, mobile, cloud, AI and Active Directory targets.

I'm a student, and I learn mostly by breaking things in CTFs and security labs, then building my own. I like problems that need patience and a clear head more than a clever one-liner.

## What I do

- **Web security:** OWASP Top 10, with hands-on work in web reconnaissance, XSS, SQLi, IDOR, SSRF, CSRF, OS command injection and business logic vulnerabilities.
- **API security:** OWASP API Security Top 10, tested on REST, GraphQL and gRPC.
- **Network security:** common protocols, port scanning, enumeration and network penetration testing.
- **Mobile security:** OWASP Mobile Top 10, Android testing and APK reverse engineering.
- **Active Directory:** enumeration, Kerberos attacks, BloodHound and privilege escalation.
- **Cloud security:** AWS testing across S3, IAM and EC2, and cloud misconfiguration assessment.
- **AI security:** prompt injection testing, following the OWASP Top 10 for LLM Applications.
